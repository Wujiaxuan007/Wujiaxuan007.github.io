# 卖话的人 · Archive

这是 `wujiaxuan007.github.io/words/` 的内容与排版约定。

## 原则

1. 原文不改：不做润色、改写、AI 优化。
2. 原排版属于作品：换行、空行、段距、缩进、居中、偏移、特殊留白都需要保留。
3. 不以截图作为前台作品本体：前台使用真实 HTML 文本 + CSS 重建排版；原始截图只作为校对依据与 provenance。
4. 特殊图形诗使用专门 renderer；《鱼》不是唯一特例，任何作品只要原稿存在独立版式，都单独记录。
5. 不确定就标记，不猜：日期、字词、标点、位置关系无法确认时保留待核状态。
6. Archive 不做文学筛选：保存的是当时真实留下的作品，而不只是“最好”的作品。

## 当前 v1

- 已建立 2015—2020 时间线。
- 已数字化一批已能逐字确认的作品。
- 其余作品已进入目录，后续按原稿逐首校对并补齐正文与 layout。
- 2026 只代表档案重新打开，不代表对旧作进行改写。
