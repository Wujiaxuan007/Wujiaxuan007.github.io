# 卖话的人 · Archive

这是 `wujiaxuan007.github.io/words/` 的内容与排版约定。

## 原则

1. 原文不改：不做润色、改写、AI 优化。
2. 原排版属于作品：换行、空行、段距、缩进、居中、偏移、特殊留白都需要保留。
3. 不以截图作为前台作品本体：前台使用真实 HTML 文本 + CSS 重建排版；原始截图只作为校对依据与 provenance。
4. 特殊图形诗使用专门 renderer；《鱼》不是唯一特例，任何作品只要原稿存在独立版式，都单独记录。
5. 不确定就标记，不猜：日期、字词、标点、位置关系无法确认时保留待核状态。
6. Archive 不做文学筛选：保存的是当时真实留下的作品，而不只是“最好”的作品。

## 当前 v1

- 已建立 2015—2020 时间线。
- 当前整理出的 30 个作品条目均已完成第一轮正文数字化。
- 已修正并核对一批原始日期，包括《南方姑娘》2015.05.20、《林夕》2017.03.05、《我在德清湖晒太阳》2017.12.22、《林夕村上春树》2019.03.17。
- 每首作品单独记录 layout；当前以 `left / center / narrow / airy / fish` 等布局属性重建原始阅读关系。
- 《鱼》使用独立图形诗 renderer；后续仍会逐首和原稿对照，继续校准特殊缩进、空行、位置与字词。
- 2026 只代表档案重新打开，不代表对旧作进行改写。

## 后续校对

第一轮转录完成不等于最终定稿。原始截图仍是校对事实源；任何发现的错字、误识别或版式偏差，都应按原稿修正，而不是按现代语言习惯润色。
